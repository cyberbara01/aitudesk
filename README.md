# AITU Desk

Виджеты рабочего стола для студентов AITU (Astana IT University) под Windows 11: карта корпуса C1, часы, расписание пар,
заметки с дедлайнами, состояние системы и ярлыки университетских сервисов. Плитки лежат прямо на обоях под всеми
окнами, не мешают работе и переживают Win+D.

## Возможности

- **Карта AITU**: три этажа блока C1 (данные проекта [aitumap](https://github.com/Yuujiso/aitumap)). Поиск кабинета
  (`223` или `C1.2.223`), этажи колесом и клавишами, зум без потери чёткости: мелкие подписи появляются по мере
  приближения. Кисть на плитке включает режим покраски: клик по кабинету красит его своим цветом. Четыре цветовые
  схемы, карта может лежать прямо на обоях без плитки.
- **Часы**: галерея готовых стилей и тонкая настройка: шрифт, насыщенность, ширина, размер, секунды, формат даты,
  компоновка, цвета, фон.
- **Расписание**: свои пары по дням недели: время, название, преподаватель, аудитория. Текущая и следующая пара
  подсвечены, дни без пар можно скрыть.
- **Заметки**: короткие задачи с дедлайном и обратным отсчётом, просроченные выделены, выполненные отмечаются кружком.
- **Приватность на рабочем столе**: текст расписания и заметок можно скрыть точками, как пароль. При наведении рядом
  со строкой появляется глаз, клик показывает её.
- **Система**: батарея, Wi-Fi, Bluetooth; имена сетей и устройств можно скрыть.
- **Ярлыки**: Digital University, Moodle, Learn и любые свои ссылки: иконка сайта, иконка из набора Fluent или первая
  буква; цвет из палитры или свой RGB.
- **Оформление**: три дизайн-языка (Windows 11, Aqua, Rice), шесть палитр от светлой до чёрной, акцент как в Windows
  или свой. Все плитки перетаскиваются и меняют размер, расположение запоминается. Оформление можно сбросить целиком
  или по разделам, ваши пары, заметки и ярлыки при этом остаются.

## Лёгкость

Все плитки работают в одном процессе WebView2, часы просыпаются раз в минуту, если секунды не показаны, а состояние
системы опрашивается раз в 10 и 30 секунд. В простое приложение почти не тратит процессор.

## Установка

1. Скачайте `AITU Desk_<версия>_x64-setup.exe` со страницы [Releases](../../releases).
2. Запустите установщик. Права администратора не нужны, приложение ставится в профиль пользователя.
3. Windows SmartScreen может предупредить о неизвестном издателе: сборка не подписана сертификатом, код открыт в этом
   репозитории, а установщик собирается автоматически из исходников в GitHub Actions.

Требования: Windows 11 (нужен WebView2, он уже входит в систему).

## Приватность

Приложение не выходит в интернет само. Сеть используется только по вашему действию: открыть ярлык в браузере или один раз
загрузить иконку сайта при добавлении ярлыка (запрос к самому сайту, в крайнем случае к сервису иконок Google).
Все настройки хранятся локально в `%APPDATA%\kz.edu.astanait.aitudesk\settings.json`.

## Сборка из исходников

Понадобятся Node.js 22+, Rust (stable) и, по инструкции Tauri, Microsoft C++ Build Tools (или mingw-w64 для цели
`x86_64-pc-windows-gnu`).

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # NSIS-установщик в src-tauri/target/release/bundle/nsis/
```

Полезные переменные окружения для проверки без ноутбука: `AITUDESK_MOCK_POWER` (`none` | `78` | `15,charging`),
`AITUDESK_MOCK_WIFI` (`off` | `SSID,bars` | `hidden,bars`), `AITUDESK_MOCK_BT` (`off` | `none` | `A;B;C`).

## Технологии

Tauri 2, Rust, React 18, TypeScript, Vite. Акрил и Mica через `window-vibrancy`, системные данные через WinRT
(`windows` crate). Иконки Fluent UI System Icons, шрифты Segoe UI Variable, Inter и JetBrains Mono.
